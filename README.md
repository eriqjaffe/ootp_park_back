This is a simple tool to convert parks using .webp textures to .png textures for older build of OOTP Baseball prior to 27.5.78.

Just drop the executable in the ballpark's folder and run it.  It will convert all the .webp files it finds to .png and update the .mtl file accordingly.  Note that it converts *all* .webp files, so you may need to re-link any 2D images inside OOTP if you care about those.

Executable binaries for Windows, macOS, and Linux can be found on the [releases](https://github.com/eriqjaffe/ootp_park_back/releases) page.  Only the Windows executable has been tested.
